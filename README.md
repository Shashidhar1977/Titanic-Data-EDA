# Titanic-Data-EDA
The Titanic Dataset Analysis project is an Exploratory Data Analysis (EDA) project developed using Python to analyze passenger data from the famous Titanic dataset. The primary objective of this project is to understand the factors that influenced passenger survival by applying data cleaning, preprocessing, visualization, and analytical techniques. This project provides practical experience in working with real-world datasets and demonstrates the complete workflow of a data analysis project.

The analysis begins by loading the dataset using the Pandas library and exploring its structure with functions such as head(), info(), and describe(). The dataset is then cleaned by handling missing values, removing unnecessary columns, and checking for duplicate records to ensure accurate analysis. Proper data preprocessing helps improve data quality and prepares the dataset for meaningful exploration.

After cleaning the data, Exploratory Data Analysis (EDA) is performed to identify trends and relationships among different features. Several visualizations are created using Matplotlib and Seaborn, including count plots, bar plots, scatter plots, and box plots. These visualizations make it easier to understand the distribution of passengers and compare survival rates across different categories.

The analysis reveals several important insights. Female passengers had a significantly higher survival rate than male passengers. Passengers traveling in higher classes were more likely to survive compared to those in lower classes. The study also indicates that younger passengers generally had better survival chances, while ticket fare showed a relationship with survival probability.

This project demonstrates essential data analysis skills such as data loading, cleaning, preprocessing, visualization, and insight generation. It highlights the importance of Exploratory Data Analysis in understanding datasets before applying machine learning models. Overall, this beginner-friendly project showcases practical knowledge of Python, Pandas, NumPy, Matplotlib, and Seaborn while providing valuable experience in extracting meaningful insights from data through effective analysis and visualization.
